### Copy my email address

This is a super simplimistic addon for thunderbird to copy your email address. Right-click on any email folder belonging to any account and click "Copy my email address" to copy it to clipboard.

### Building

```
zip -r -FS tb_copy_my_email.zip addon/*
```
